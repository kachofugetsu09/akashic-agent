第一次使用或忘记密码？

第一次使用时，初始密码在启动日志里。也可以在服务器上运行下面的命令，免密进入或重置：

python main.py web-login      # 打印一次性登录链接
python main.py web-passwd     # 重置为临时密码，所有设备退出
docker compose exec akashic python main.py web-login

也可以在 Telegram/QQ 里让 Akashic 帮你重置网页密码。

设置你自己的密码

初始或临时密码出现在日志或聊天里，保存新密码后就会失效。以后在任何设备上都用这个密码登录。

至少 10 个字符。不要求大小写或符号，长一点比复杂更有用。
