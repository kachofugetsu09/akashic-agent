# Akashic Mobile v0.8.0 内测版

## 发布定位

v0.8.0 是首个面向 Akashic 用户的 Android Agent IM 内测版。它不是 WebChat 的简单外壳：Android 负责设备身份、安全存储、离线投递、通知和系统分享；WebSocket 负责流式事件；Akashic 核心继续拥有会话、Agent 生命周期和插件能力。

```text
┌──────────────── Android ────────────────┐
│ Room 离线状态 · 安全密钥 · 通知 · 分享 │
└──────────────────┬──────────────────────┘
                   │ durable WebSocket
┌──────────────────▼──────────────────────┐
│ Akashic 会话 · thinking/tool · 插件 UI │
└──────────────────┬──────────────────────┘
                   │ plugin lifecycle
┌──────────────────▼──────────────────────┐
│ KV Cache · Observe · Akasha · Fitbit…  │
└─────────────────────────────────────────┘
```

## 完整功能

### 连接与安全

- WebChat 一次性二维码配对、六位数字核对和应用内重新配对入口。
- 配对后的设备密钥由 Android Keystore 加密保存，不需要每次扫码。
- 同时支持局域网和 Cloudflare Tunnel；网络切换时自动重连。
- WebSocket 事件序列、确认游标和离线 inbox 可恢复，发现事件缺口时重新同步，而不是继续展示错误顺序。
- 顶栏直接表达连接正常、网络不稳、正在连接、正在重连和断开状态。

### 日常 IM

- mobile 会话列表、搜索、切换、新建会话和服务端历史同步。
- 用户与 Agent 消息时间、独立复制、引用回复；引用复用服务端既有 reply 协议。
- 长按进入多选，可按对话顺序批量复制；返回键退出上下文模式。
- 每个会话独立保存未发送草稿，切换会话、重启应用和同步期间不会串稿。
- 保存阅读锚点、未读位置和回到底部状态；进入新会话默认定位到最新消息。
- Markdown、代码块、链接、列表、图片和常见富文本渲染。
- 会话之间使用克制的分隔线，颜色只承担连接、选择、错误和 Agent 过程语义。

### Agent 原生过程

- thinking、tool call、tool result 和 final answer 按事件流增量生长。
- thinking 使用圆点，工具调用使用菱形；时间线从顶部端点向下延伸并跟随输出滚动。
- 完成后自动收起过程并显示思考耗时；可重新展开查看全过程。
- 工具详情可展开参数、结果和错误，支持分区复制；隐藏状态不会残留在键盘或读屏焦点树。
- 运行中可停止当前 turn；命令面板只展示服务端真实支持的命令。
- 插件提供 token 指标时，仅在对应 turn 尾部显示本轮输出 token；插件关闭后不保留伪数据。

### 文件与媒体

- 多附件选择、上传进度、失败重试、图片预览、文件下载和 Android 分享。
- 小附件自动缓存；大于等于 10 MiB 的历史附件按需下载，避免打开会话就占满移动网络。
- 分片下载支持断点恢复、SHA-256 校验和进度展示；快速重复点击复用同一下载任务。
- 远端图片与 meme 走统一媒体出站链路，不把二进制内容塞进消息文本。

### 弱网、后台与主动消息

- 发送中的消息进入本地 outbox；断线时保留并在恢复后继续投递。
- 草稿、消息、确认游标和待通知记录由 Room 事务持久化。
- Agent 主动消息与普通 final message 使用同一持久化通知队列，应用进程重启后仍可补发。
- 后台通知支持点按打开对应会话和直接回复；相同服务端消息不会重复提醒。
- 前台服务维持实时连接，并提供明确的连接状态通知。

### 插件扩展

- 抽屉只显示一个轻量“插件”入口和运行数量，不把插件做成首页卡片墙。
- 插件目录只列出当前运行且声明移动 UI 的插件；选择后进入全屏 Material 3 看板，左上角始终可返回。
- 插件目录与资源支持热更新；单个插件不可用不会拖断聊天连接。
- 已支持的移动面板包括 Akasha 召回检查、KV Cache turn token、Observe 状态与错误、主动反馈、情绪状态和 Fitbit 健康信息；内容由插件注册，核心客户端不内建插件业务数据。

## 安装和升级

1. 从私有仓库 `kachofugetsu09/akashic-mobile-releases` 下载 `Akashic-Mobile-v0.8.0.apk`。
2. 在 Android 系统中允许当前下载来源安装应用。
3. 从 v0.7.x 直接覆盖安装会保留配对密钥、会话、草稿、附件缓存和通知状态。
4. 首次安装在 WebChat 打开“连接 Android 手机”，扫描一次性二维码并核对六位数字。
5. 需要更换服务端时，在应用连接设置中选择重新配对；操作会立即断开当前连接，旧密钥保留到新配对成功写入。

## 已知限制

- 当前只发布 Android；iOS、桌面独立客户端和应用商店分发不在本次范围。
- APK 是完整覆盖安装，不是二进制增量更新。
- 第一次配对仍需要能够访问同一 WebChat 的二维码页面；Pixel 相机识别失败时可使用应用内手动粘贴扫码结果。
- 插件看板只展示插件明确注册的移动能力，不承诺复刻桌面 dashboard 的全部信息密度。
- Release WebView 默认关闭远程调试；自动化验收优先使用 instrumentation，少量触控路径保留人工真机验收。

## 故障恢复

- 一直显示“正在重连”：先确认公网域名返回服务响应，再检查 agent、chat-proxy 和 tunnel 三个进程；Mobile Lab 手工重启 agent 后还需要重启共享其网络命名空间的两个 sidecar。
- 提示事件序列缺口：保持应用在线等待自动全量同步；不要清除应用数据。重复出现时保留 runtime 和 Android 日志。
- 会话不可用：从抽屉切换到仍存在的 mobile 会话，或新建会话；重新配对不会把旧服务端不存在的会话伪装成可用。
- 插件面板为空：确认插件正在运行并声明 mobile UI；插件关闭时客户端按设计移除入口和 turn 指标。
- 只有在配对状态损坏且重新配对也失败时才清除应用数据；正常升级不需要清缓存。
