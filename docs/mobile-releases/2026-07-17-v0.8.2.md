# Akashic Mobile v0.8.2

## 本次修正

- 状态栏 small icon 直接采用 Akashic 女孩大头头像，只保留短发、叶饰、花朵、表情和下巴弧线。
- 移除 v0.8.1 中误加的脖颈与肩膀底座，避免小尺寸下读成奖杯或人偶底座。
- 继续提供 mdpi–xxxhdpi 五档单色 alpha 资源，由 Android 在明暗状态栏中自动着色。
- 版本升级为 `0.8.2 (23)`，可从 v0.8.0 或 v0.8.1 无损覆盖安装。

## 验证

- Android 资源编译通过，五档图标均具有透明边角和抗锯齿 alpha。
- Android release unit、Lint、R8、assemble 与 APK v2 签名通过。
- Pixel 7 无损覆盖安装后，包内版本与设备读回均为 `0.8.2 (23)`。
- Pixel 7 通知折叠区域实测只显示女孩头像，没有脖颈或肩膀；设备 APK 与构建产物哈希一致。
- 应用日志无 FATAL、WebView render loss 或协议错误。
