# Akashic Mobile v0.8.1

## 本次更新

- Android 系统分享现可把单段文字、单文件或多文件可靠送入当前会话的输入区。
- 分享内容会保留原草稿、引用和附件，不会自动发送；进程中断后仍可恢复，失败时可重试或丢弃。
- 状态栏小图标由通用圆形勾号改为 Akashic 女孩剪影，保留短发、叶饰、脸部和脖颈轮廓；系统可在明暗状态栏中自动着色。
- 版本升级为 `0.8.1 (22)`，可从 `v0.8.0` 无损覆盖安装。

## 验证

- Web 移动状态测试 `36/36`、TypeScript 和 ESLint 通过。
- Pixel 7 定向 instrumentation `54/54` 通过，真实 Android 系统文字分享闭环通过。
- Android release unit、Lint、R8、assemble 与 APK v2 签名通过。
- Pixel 7 无损覆盖安装后，包内版本与设备读回均为 `0.8.1 (22)`，设备 APK 和构建产物哈希一致。
- 真机状态栏与通知抽屉验证新图标可辨识；应用日志无 FATAL、WebView render loss 或协议错误。
