# 0090 · 工具结果持续可见

- 状态：accepted
- 日期：2026-10-05
- supersedes：[0081](0081-content-views-keep-original-messages.md) 中的自动折叠策略
- 关联条款：CTX-001、CTX-008、STA-002

## 背景与决定

K3 价格查询的实际请求显示：长工具结果完整展示一次后即被收起，长回读也再次被收起。
该轮有 10 次回读，同一官方页面回读 4 次。没有对照实验能量化因果损失，但维护者已明确
要求移除遮盖，而非再调阈值或引入最近轮次窗口。

删除自动折叠分支。当前上下文内的工具文本始终走基础全文投影；已有回读继续展开原文范围。

```text
┌──────────────────────┐
│ 原始 ToolResult      │
└──────────┬───────────┘
           ▼
┌──────────────────────┐
│ 每轮请求保留全文      │ ← 旧回读引用展开原文范围
└──────────────────────┘
```

保留 `read_content` 与其内容声明，使旧消息和已冻结的回读调用仍可解析、执行和恢复。
已有安装的 `fold_after_chars` 只兼容校验，标为停用，不参与渲染。这样不用改写持久配置或
历史消息；新配置也无法重新开启遮盖。通用内容视图及请求回执不是遮盖策略，不随之删除。

## 代价与状态边界

单次输入可能变大，仍由现有上下文窗口、摘要和容量拒绝处理。原始消息、回读引用、
成功回执及冻结请求均保留；只由原 owner 按既有协议追加，没有更新或减少历史数据。
已经冻结的旧请求仍精确恢复，之后新准备的请求使用全文。发布通过内置插件正式更新生效。

不新增替代遮盖策略。以后只有同快照、同模型的任务完成率与成本对照支持，且维护者明确
接受时才重新考虑。恢复旧代码会恢复旧策略，但不需要回填消息。

## 验收

复用真实 PluginManager、MessageLog、Tools、Models 集成场景：多轮成功输出后原文仍在；
全文回读及 Unicode 范围可用；关闭并重开后长回读仍完整；旧 opaque continuation 清空；
provider 失败、同 ID 恢复、原消息逐字段与工具效果保持既有断言。模型质量提升未做 A/B 验证。
