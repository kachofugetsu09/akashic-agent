# 0144 · 纸感使用校正后的配色

- 状态：accepted
- 日期：2026-11-06
- 关联条款：WEBUI-001～WEBUI-007
- Supersedes：[0142](0142-theme-families-and-palette-rules.md) 中保留原纸感与另列校正版的决定；配色规则和选择方式继续有效。

## 决定与理由

维护者要求移除未经校正的旧纸感，用「纸感·校正」替换，并统一称为「纸感」。
菜单只保留一项纸感，共六套配色；纸感的亮、暗两面完整采用校正版颜色，默认主题也使用它。
不保留旧颜色作为隐藏选项，也不另列同色的校正版。

```text
┌─────────────────────────┐
│ 原纸感 / 原纸感·校正    │
└────────────┬────────────┘
             ▼
┌─────────────────────────┐
│ 纸感：使用校正版颜色    │
│ 亮 / 暗 / 跟随系统      │
└─────────────────────────┘
```

保留纸感现有 `paper` 配色身份和 `light` / `dark` 主题身份。
已保存的 `tuned-light`、`tuned-dark`、`system-tuned` 偏好分别读取为
`light`、`dark`、`system-paper`，不丢失用户选择的明暗模式。
首帧和运行时共用这份映射，避免原校正版暗色用户在刷新时先看到亮色。
菜单此后只写现行身份；读取旧 cookie 不重写 cookie，也不改服务器业务数据。

## 代价与验收

选择原纸感的用户会看到校正后的颜色，这是本次明确要求的变化。
通过恢复前一发行版可恢复原配色目录；浏览器保存的旧偏好仍保留。

验收覆盖默认与既有两套纸感的亮、暗、跟随系统偏好，首帧与页面就绪后保持一致；
宽窄屏菜单只有一个「纸感」，颜色与原校正版一致。其他五套配色不变。
