# 0154 值班：自己去看、自己接着看、到头就拆；猜的先放便签

状态：proposed / implemented for review
关联条款：PRO-004～PRO-006

## 背景

0152 之后主 Agent 会回头问一件事的结果，但仍然只在用户开口时才去看一次，看完就结束：

- 用户问过在路上的东西到哪了、一笔钱到账没有、一个价格现在多少。它每次都够得着（带登录态的浏览器、手机），答完就不再管，下次还要用户自己来问。
- 它从一次闲聊里猜出一个长期兴趣，自己写了采集脚本，两次主动说都没人接，仍然继续排第三次；这类自己猜的东西没有期限，也不会自己撤。
- 它把"他不怎么回主动消息"当成结论写进嘱托和便签（"等他开口再说"），之后每一轮都照此执行。
- 0151 加的 `watch/sources/` 脚本和订阅插件已有的脚本来源是两套做同一件事的办法，后者有试跑、版本、健康状态和退订，前者都没有。
- 记忆会被之后每一轮值班读到，它却把只见过一次的事直接写进去，而且改了什么没有记录。

## 决定

1. **够得着就先去看。** 提示词写明后台回合和聊天时一样能用浏览器、手机、订阅和命令行，用户的东西都可以看；不确定能不能看到，先看一次再说。
2. **他在等的事自己接着看。** 用户问一件还在变的事现在怎么样了，回答不算做完：很快到头的定一两个时间回来看；要好些天的接成订阅来源；只在手机应用里的定时间醒来看。到头了告诉他，然后把来源退订、嘱托删掉。已经结束的事和常识问题不搭任何东西。
3. **他要的和它猜的分开。** 他开口要盯的，盯到他说停。它自己猜的只是试探：写明到期日，到期前没被接过话不续；同一条线主动说过两次都没人接就停下并拆掉。整体不回消息仍是常态，不构成少说的理由。
4. **放下就是删掉。** "他问起再说"不算着落。
5. **外面的内容走订阅插件。** 技能说明把网页、接口和要登录的页面指向订阅的脚本来源；`watch/sources/` 只留给看本机状态。
6. **猜的先放便签。** 用户明说一贯如此的事、要它记住的话、或几处印证过的，写进记忆；从某一次的话或某一天的数据推出来的倾向先记在便签，印证后再进记忆。
7. **记忆改动留痕。** 值班叫醒的每一轮结束后，对比记忆文件，把增删的行写进当天的值班日志，面板里能看到。

提示词里只写原则，不举具体的应用或场景。

## 依据

新增一套能动性评测（23 条用例各 3 遍，被测模型是生产用的主 Agent 模型，工具是有状态的桩：文件、订阅、浏览器页面、手机屏幕）。留出集的场景从未出现在提示词里，转录也不读。分数见 PR 描述。另用 0151、0152 的两套评测做回归。

评测脚本和素材含用户的真实记忆与对话，留在本机，不进仓库。

## 已知限制

- 评测里的页面和手机屏幕是假的，只能说明它的决策；真实页面抓不抓得到要看上线后的实际情况。
- 只在手机应用里的东西只能靠它定时醒来看，每次是完整的一轮模型调用。
- 记忆改动只记录值班叫醒的回合；它在主对话里改记忆不在此列。
- 它已经写下的旧嘱托不会因为提示词改了而自动消失，需要它在复盘时自己清，或人工清一次。
