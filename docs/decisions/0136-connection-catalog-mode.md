# 0136 · 连接的模型范围：全部模型或仅所选

- 状态：accepted / implemented for review
- 日期：2026-10-28
- 关联：设置 → 模型；0135 额度；参考 magpie 的「供应商列表 / 仅所选」

## 问题与决定

以前新建连接必须先挑一个模型并发一次对话验证，之后每个模型都要单独添加；服务商上新模型时也不会出现。
用户要的是「填密钥 → 添加 → 能用」。

连接增加 `catalog_mode`：

| 值 | 含义 |
|---|---|
| `all` | 服务商目录里的对话模型全部启用；以后同步目录时新上的型号自动收进来，下架的照旧停用 |
| `picked` | 只用用户勾选的模型（旧行为，旧库按此补列） |

- `add_connection` 可带 `catalog_mode=all`，或带 `adopt_models` 只收目录里的这几个。Models 先探测连接，再读取并补全目录，连接与模型在同一次写入里提交；探测或读取失败就什么都不写。
- 新命令 `set_catalog_mode`：切到 `all` 时读取目录补齐；切到 `picked` 只改标记，已有模型不动。
- 目录投影带 `catalogMode`，设置页据此显示「全部」勾选。

## 取舍

- 收进来的模型不再逐个发对话验证：目录能用这把密钥读出来，就说明连接可用；单个模型不可用时由调用失败暴露，与订阅登录后的行为一致。
- 目录没声明用途的型号按对话模型收，名字含 `embed` 的跳过；向量模型仍需显式试算维度。
- 用户在 `all` 模式下取消某个模型时，设置页先切到 `picked` 再删除，Models 不维护「排除列表」。
