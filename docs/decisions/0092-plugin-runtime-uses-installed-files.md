# 0092 · 插件运行使用已安装文件，不保存强快照

- 状态：accepted
- 日期：2026-10-06
- 关联：Issue #1039；PLG-002、PLG-003、PLG-010、PLG-013、STA-003
- supersedes：0082 的运行输入归档方式、0091 Skill 来源记录的资源归档要求

## 背景与决定

维护者确认外部环境变化无法由代码快照消除，要求移除整个 PluginArchive 机制。
运行时使用安装 owner 发布的插件目录、发行版代码与当前配置；保留版本选择和生命周期，
不再复制插件代码、Skill 资源或保存历史配置闭包作为调用前提。

```text
┌───────────────────┐    ┌──────────────────┐
│ 镜像 / 安装目录    │    │ 当前选择与配置    │
└─────────┬─────────┘    └────────┬─────────┘
          └──────────┬───────────┘
               Context / Fiber
                     │
            调用接纳 → 排空 → 清理

会话与回执：保存真实消息、结果、操作身份，不保存执行环境快照。
Skill：使用时读取正文与实际资源目录，文件变化后重新加载。
```

## 保持与改变

安装继续检查插件身份、入口和硬依赖，发布完整目录后才加载。更新不覆盖运行中的版本；
旧 owner 排空前不得删除所用文件。卸载保留 plugin-data、配置、会话、消息和操作回执；
内置卸载只保存停用选择，外置卸载在排空后移除安装代码。

已完成工具结果原样回读，不重跑；未完成调用交给当前 provider 检查兼容性。
缺少目标、旧业务格式不兼容或外部结果未知时明确失败，不静默转移或盲目重复操作。
旧 Skill 绑定不能再承诺恢复历史资源树；未完成旧格式调用明确拒绝，允许用户重新加载。

不采用永久代码与配置归档，也不把它改名为另一套历史输入仓库。
当前安装记录、当前配置、Python 依赖环境和操作回执分别由原 owner 保存；它们不是历史执行环境。
源版本用于安装选择与诊断，不承诺文件系统、数据库、凭据或远程环境可回滚。

## 持久化与升级

新调用不增加 skill-files。旧归档与旧绑定保持原样，物理删除不属于这次源码退役。
现有必要安装选择通过显式离线升级转换，先保存元数据恢复点，再持锁校验来源与数据身份。
普通启动不自动迁移，不维持旧归档双读双写，不修改 sessions.db/messages 的既有正文。
当前选择可原子更新，操作失败保留可区分的未提交与不确定结果。

## 验证与重议

使用隔离 HOME/workspace/plugin home 运行真实组件或应用 E2E，覆盖热读取、安装、更新、
卸载、重装、重启、配置、依赖失败、排空与消息保全。不新增单元测试。
若未来明确需要可审计的环境重放，应由专门导出工具保存显式材料，不重新进入普通运行链。
