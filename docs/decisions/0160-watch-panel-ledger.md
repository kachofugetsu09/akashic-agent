# 0160 值班面板：一天是一张流水，嘱托和便签按结构排版

状态：proposed / implemented for review
细化：0153

## 背景

0153 的“这一天”页有四块：回合列表、各来源的 24 小时条带、事件列表、用量。实际用下来有三个问题：

- 回合行上显示的是它收尾时自己写的第一句话，多数是“已完成值班唤醒处理：”这样的套话，要点开才知道它做了什么。
- 条带用竖线的粗细和高矮表示去向，颜色几乎一样，要对着图例解码；它回答的问题（哪个来源几点来了事）也不是打开面板时最想知道的。
- 嘱托和便签是原文，方括号标记和 Markdown 记号都要自己读。

## 决定

1. “这一天”改成一张按时间倒排的流水，三列：时间、事情、它怎么处理的。后台回合、你们的对话、要紧的事件、来源报告的状态变化都是其中的行。
2. 回合行直接显示它留下的东西：对用户说的话原样摆出来，改过的嘱托、便签、记忆和其他文件逐条列出。这些从回合里成功的工具调用按参数形状算出来（带发送对象的消息、带路径的写入），不认具体的工具，也不用它自己写的总结。点开仍是 0153 的回合详情。
3. 只记了一笔的事件不逐条占行，两件要紧事之间的折成一行，写明各来源几条，点开才列出来。
4. 来源报告的状态变化是分隔行，文字是来源的原话。界面仍然不认识任何一种具体的来源或状态。
5. 当天的页面在最上面列出嘱托里定在今天、还没到的时刻，和“现在”隔一条线。
6. 右边一列的说法（对你说、悄悄做了、进了待看、叫醒了它）都有文字，颜色只是辅助；颜色只用宿主的变量。
7. 嘱托页按文件自己的格式读成三组：到点它会自己回来、出了这些事会被叫醒、这些事不打扰你。每条一行标题加有效期，点开是原话，页底可以看原文。便签页按它自己的小标题分节，日期单独一列。
8. 删掉各来源的条带和事件筛选。

## 已知限制

- “留下了什么”只认两种形状的调用；它用命令行改的文件、在外部系统里做的事不会出现在这一列，要点开看每一步。
- 改动的文字取新增的头两行并截短，看不到完整的前后对比。
- 嘱托和便签的排版依赖它们现在的写法；写法变了就退回成一条条原话，原文始终可看。
- 仍然只读。
