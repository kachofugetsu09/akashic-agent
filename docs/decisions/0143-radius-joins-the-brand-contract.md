# 0143 · 圆角进入品牌合同：五级刻度与同心规则

- 状态：accepted / implemented for review
- 日期：2026-11-06
- 关联条款：WEBUI-007
- 细化：0043 的品牌 token 合同；改写[纸张品牌系统](../design/akashic-paper-brand-system.md)中「圆角留在组件 CSS」的约定。

## 背景

0043 把颜色、墨色、规则线和字体收成品牌轴，但圆角被明确留在组件 CSS，理由是「数值相同也不代表换品牌时要一起变」。一年下来，组件里的圆角实际上已经收敛成一套隐含刻度：控件和行用 8，卡片和浮层用 12，浮动元素用胶囊。可是这套刻度没有 owner，数值同时来自四个地方：

- `--md-sys-shape-corner-*`，即 Material 的 4 / 8 / 12 / 16 / 28 / 全圆；
- shadcn 的 `--radius: 0.75rem`，派生出 12 / 10 / 8；
- models 插件自建的 `--models-radius-*`；
- 写死的 px：聊天 CSS 里仅 8px 就出现了 46 次。

结果是同高的控件形状不一：32px 高的按钮有 8、10 和胶囊三种。嵌套也不同心：附件卡 12 里的图标块是 8，间距 8；回复条的 28 套在 14 的卡里。连 bug 都看不出来——桌面回复条被父级裁成直角，却没有任何规则能指出它错了。

## 决定

1. `brand-tokens.css` 新增形状轴 `--ak-radius-*`，只有五级：`xs` 4、`sm` 8、`md` 12、`lg` 16、`full` 胶囊。按元素尺寸和角色取值，不按组件名命名。
2. 子元素贴着父级的角时，嵌套圆角从外层推导：内圆角 = 外圆角 − 间距（含边框），不小于 `xs`。只有横竖两个方向的间距都小于外圆角时，同心关系才看得出来；否则按元素自身的尺寸取值。
3. 胶囊只给浮动、临时出现的元素和圆形图标钮。按钮和设置页、侧栏的控件一样用 `sm`。
4. 只有一侧有边框的块（引用块、侧栏竖线等）不加圆角。代码块用 `sm`，与气泡、附件卡同属一套刻度；这一条改写了 #924 对齐 DSH 时定下的直角。
5. `--md-sys-shape-corner-*` 和 shadcn 的 `rounded-*` 变成刻度的转接：前者是迁移别名，后者在 Tailwind 配置里接到刻度上。models 插件的私有圆角变量删除，直接引用刻度。

## 理由

外部设计系统的做法一致：

- 刻度要少，来源只有一个：Radix 用 6 级刻度乘一个全局系数，Material 3 也是固定的 shape 刻度；
- 圆角与元素尺寸成比例（REI Cedar、Appwrite）；
- 嵌套要同心，Apple Liquid Glass 把它作为基本原则，SwiftUI 有 `ConcentricRectangle`；
- 胶囊要省着用，形状本身就表达用途（VTEX Shoreline）。

把刻度做成品牌轴之后，「这里该多圆」从逐处手调变成按角色查表，嵌套时用公式推导。0043 担心的「换品牌时被迫一起变」反而成了好处：调整整体性格只需改五个值。

squircle（`corner-shape`）目前只有 Chromium 支持，混用时普通圆弧会显得突兀，所以暂不采用；等 Safari 和 Firefox 支持后再评估。

## 影响与回滚

- 聊天、外壳主题、dashboard 和 models 插件的圆角改为引用刻度。数值大多不变，变化的有：
  - shadcn 按钮与输入框 10 → 8；输入框里的 kbd、xs 小按钮 7 → 6；
  - shadcn 菜单 10 → 12（菜单项 6 → 8），提示 10 → 8；
  - 新建分组对话框的按钮胶囊 → 8；
  - 输入卡：桌面 14、窄屏 22 的两种方卡改为单一形状，圆角取单行高度的一半（桌面 24、平板与矮屏 28、手机 26），见 design.md 2.1；
  - 抽屉 18 → 16；
  - `MaterialButton` 胶囊 → 8；
  - 代码块直角 → 8；
  - 附件图标块 8 → 4；
  - 气泡内的会话引用条 8 → 4。
- 其它插件里写死的圆角数值与刻度相同，新改动时顺手迁到刻度上，本次不批量改写。
- 回滚时还原 CSS、Tailwind 配置和文档即可，不涉及数据和协议。

## 验收

- 组件总览页（`frontend/chat/harness/gallery.html`）和真实聊天页在浅色、深色、桌面、390px 窄屏下逐格检查。总览页里实际只剩 0 / 4 / 6 / 8 / 12 / 16 / 胶囊和按公式推导的值；这只对总览页覆盖的组件成立，不是全仓结论：其它插件和少量焦点描边（如 `message-view.css` 的 0.3125rem）仍写死数值，等改到时再迁。
- 嵌套处实测间距与圆角符合「内 = 外 − 间距」。
- 真实发送一条带引用的消息，输入卡、回复条和发出的消息正常。
