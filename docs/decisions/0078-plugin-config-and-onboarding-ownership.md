# 0078 · 配置由插件拥有，引导只组合当前状态

- 状态：accepted
- 日期：2026-09-28
- 关联：ONB-001、PLG-003、PLG-014、PLG-016、0070、0072

## 背景与决定

维护者确认仅覆盖内置插件的首次配置，要求卸载 Wake 或引导不破坏其他功能。

1. 每个业务插件拥有开关、字段、校验、持久配置和独立设置页。功能运行分支与设置分支分开。
2. onboarding 是普通可卸载插件，只有贡献目录、拓扑排序和页面，没有业务 writer 或持久进度。
3. Core 提供真实 provider 边、自身配置输入应用与回执。配置通过现有固定输入和 selection CAS 采用，由宿主异步完成局部排空，不能在自身请求内等待自身卸载。
4. 顺序按拓扑层级、去重直接依赖数、plugin ID、step key。分组只组织入口，不表示业务依赖或另一套总开关。
5. 可选功能明确开启或关闭；上游不可用只阻塞功能，不替用户写关闭。默认启动先初始化后迁移，发行组合仍由安装清单拥有。

## 理由与影响

业务字段和运行条件只能由功能插件解释；正式输入的提交与生命周期必须由已有宿主 owner 完成。客户端无法替代这些边界。设置与引导复用同一表单和 API，避免平行配置事实。

新安装的可选功能使用 `enabled: null` 表示未决定，已有配置和旧默认保持。移除旧 CLI 问答，保留插件自有离线升级命令与恢复点。关闭或卸载不删除会话、记忆、凭据、调度或主动流程历史。
