# 0056：插件更新中进程死亡时恢复旧指针

- 状态：accepted，更新回退已实现；完整发布接线待验收
- 日期：2026-09-06
- 范围：插件安装更新、候选晋升与启动恢复

## 决定

维护者明确要求只考虑进程存活时的正常更新，以及更新中进程突然死亡后的旧版恢复。更新前持久保存旧指针和受影响插件的启用状态；存活时正常准备、验证、排空与切换，明确提交成功后保留新版。中途死亡后，下次启动先恢复旧状态，再按旧版启动。

不自动续跑安装、重拉源码、重建候选或继续业务验证。新的安装/更新由新请求发起。使用现有 ReloadJournal，不增加可恢复执行队列、父子 reload 血缘或第二套 Attempt。候选验证仍需实际证据；进程与端点仍由原生命周期 owner 关闭和核对。

## 持久化与验收

恢复点在首次可见指针或启用记录变化前落盘；只有已确认的旧状态和本次新状态可参与回退，第三种外部状态明确报错。原插件数据、消息和旧 artifact 不因回退减少，未引用的新 artifact 不自动清理。

通过真实进程中断验证：安装指针写入后、晋升指针写入后但提交前均恢复旧版；提交后重启保留新版；未知指针拒绝覆盖；旧插件数据和无关插件状态保持不变。
