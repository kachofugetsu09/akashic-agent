# 0120 · 运行诊断只面向运维

- 状态：accepted
- 日期：2026-10-14
- supersedes：[0119](0119-local-runtime-diagnostics.md) 的本地页面与浏览器操作决定
- 关联：PLG-015、PLG-016

维护者明确诊断由 SRE 运维，普通用户界面应保持清爽。因此移除诊断页面、导航贡献、
前端源码和静态资源，保留采样、版本化只读服务、HTTP 导出与限时剖析。

```text
┌────────────────────┐       ┌─────────────────────────┐
│ 有界采样与操作记录 │──────▶│ SRE / 独立运维消费者    │
└────────────────────┘       │ 服务读取或后端 HTTP     │
                             └─────────────────────────┘
┌────────────────────┐
│ 用户对话界面       │  不注册诊断页面或导航
└────────────────────┘
```

HTTP 使用已有无前端模块的 Dashboard 注册，不增加监听器或空 JS 模块。部署入口仍负责
访问控制，宿主仍执行浏览器请求约束；接口细节见[插件 README](../../plugins/runtime_diagnostics/README.md)。
只隐藏按钮会留下不再需要的页面、轮询和资产，因此完整移除前端贡献。Shell 仅有一个页面时
本就不显示顶部导航，不增加诊断专用布局规则。

0119 的有界内存、缺口、脱敏、独立读者和生命周期合同保持不变；没有业务数据写入或迁移。
验收覆盖无前端模块、无顶部导航、真实 HTTP 采样与剖析、导出、浏览器请求拒绝、换代和关闭。
只有产品明确要求普通用户自行诊断时，才重新讨论前端。
