# 0084 Computer 保存身份，空闲时释放桌面

- 状态：accepted
- 依据：维护者要求按需唤醒、无操作满 10 分钟回收，并保留已保存的身份。
- 关联：PLG-017、STA-003、BAK-001、ERR-001

## 决定与理由

Computer Workload 常驻控制服务与 OpenCLI 定时器，浏览器、桌面和输入 driver 按需运行。
首次 Computer 调用或人工打开面板唤醒主浏览器；轮询、健康检查和自动重连不唤醒。
人工实际输入、一次完整刷新和 Agent 的整个 Turn 都计入使用。占用结束后，无操作满
10 分钟关闭重资源；面板保持打开不延长占用，休眠后提供人工唤醒入口。

```text
┌──────────────────────────────────────┐
│ Workload：控制服务、OpenCLI 定时器    │
└─────────────────┬────────────────────┘
                  │ 唯一启停 owner
┌─────────────────▼────────────────────┐
│ 主 Chromium、桌面、输入 driver       │
│ 人、Agent、OpenCLI 复用同一个实例    │
└─────────────────┬────────────────────┘
                  │ 顺序使用
┌─────────────────▼────────────────────┐
│ 磁盘 profile、HOME、config：保存身份  │
└──────────────────────────────────────┘
```

Chromium 禁止独立实例同时写入同一 user-data-dir。刷新复用主实例的专用标签。
只在 Workload 首次启动、Controller 已确认旧容器停止后清理遗留 singleton 链接。
日常唤醒不删锁，先等待上次停机完成；释放失败关闭启动准入并明确返回错误。
profile、HOME 和 config 沿正常浏览器使用原位更新，空闲回收不删除这些目录。
JS 绑定、DOM、页面运行状态和桌面进程失效，下一次调用重新初始化。保存文件沿原
输出 owner 保留。正式身份目录的迁移或删除仍需要用户授权与可恢复备份。
回退使用上个插件 artifact 和固定镜像；本改动不改变 profile 格式。

不先引入 Kubernetes、microVM 或常驻 warm pool：本次目标是减少空闲重资源，现有
Workload 已提供隔离。约 1 秒是要测量的浏览器可操作目标；完整链路持续不满足时再
评估快照恢复。保存身份不能延长站点 token 的有效期，刷新成功须看对应站点结果，
不能只凭 CLI 退出码或批次标记。

## 验收

在隔离目录验证冷启动、并发唤醒、Turn 与刷新占用、休眠后身份使用、主 profile
单 writer、默认 10 分钟回收，以及面板保持打开时不自动唤醒。启停失败应明确报错，
不能把控制服务就绪报告成浏览器已可操作。
