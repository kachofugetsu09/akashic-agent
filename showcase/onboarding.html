相对现在改了什么

引导的骨架不变：步骤仍然由已安装插件贡献，顺序仍由运行时依赖图计算。变的是它对用户说什么、出现在哪里、一次让人做几件事。在上方切换「已安装插件」，能力页和进度条会随之增减；关掉 Telegram 时，Wake 会提示它缺少接收渠道。

从设置弹窗里出来

现在
嵌在「功能设置」对话框里，左边是设置目录，像在填后台表单。
改为
首次启动时占满整屏的单列纸面，只有进度、一个问题和一个按钮。以后在设置里也能重新打开。

按好处命名，不按插件命名

现在
「Akasha 情景记忆」「Wake 主动联系」「Telegram 发送 / 接入」。
改为
「记住你们聊过的事」「在合适的时候主动找你」「在 Telegram 里找到它」，插件名降为小字来源。

只有一步是必需的

现在
五步平级，每一步都要「做出决定」才能往下走。
改为
连接模型是唯一必需项。其余能力在一页里用开关挑选，只为打开的能力出配置步骤。

先让人看到会得到什么

现在
直接给表单，用户不知道开了之后会怎样。
改为
每张能力卡打开后显示一段示例对话或通知，配置前就看到回报。

状态自己更新

现在
「刷新状态」按钮，「已启用 · 待完善配置」「依赖项未就绪」这类系统用语。
改为
连接后就地给出结果和一句试回复；依赖关系写成人话：「Wake 需要一个接收渠道，已为你排在 Telegram 之后」。

终点是第一句话

现在
完成页列出配置状态，按钮写着「进入工作台」（工作台已退役）。
改为
完成页直接给输入框和几条起手话题，引导结束即对话开始。手机上动作栏固定在拇指区。
// 插件侧的合同只多三个可选字段；不填时退回今天的行为（嵌入设置分节）。
Step(
  key="configure", title="Wake 主动联系", group="proactive", route="wake-settings", status=...,
  pitch="在合适的时候主动找你",            # 能力卡标题，用户语言
  benefit="天气突变、日程临近、你提过的事有了进展时发消息给你。",
  preview=Preview(kind="notification", lines=(...)),   # 示例对话 / 通知
)
# 模型连接等必需步骤用 required=True 标出；其余都进入「能力」页由用户挑选。
