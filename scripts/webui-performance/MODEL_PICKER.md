# 模型选择器打开与筛选基准

本轮只调整模型和思考强度面板的挂载时机。原路径先挂完整列表，再读取触发钮几何并写入面板位置；
新路径在同一轮绘制前确定位置，再挂列表。完整目录、筛选、焦点、动画时长和选择提交规则不变。

```text
旧：点击 → 挂列表 → 强制布局读位置 → 写定位样式 → 再算列表样式 → 绘制
新：点击 → 读触发钮位置 → 带定位样式挂列表 → 绘制
```

线上 62 个模型的 CPU 四倍节流追踪显示两次约 4,200 个元素的样式计算；未发现打开菜单依赖模型网络读取。
隔离验证使用 64 个固定模型、5 个来源。它通过 ModelsStore 在新 workspace 中写入真实配置，
随后走真实 `chat.models`、插件目录、HTTP 和渲染器；连接指向本地未使用的端口，不带真实凭据，
不模拟模型请求成功，也不验收模型可调用性。选择与收藏验收只在隔离实例和新浏览器上下文执行。

## 复现

分别构建两版插件 UI，启动两个新目录的 Runtime，保留各自的冻结模块：

```sh
npm run build
.venv/bin/python scripts/webui-performance/serve-startup-runtime.py \
  --state /tmp/picker-baseline-new --port 24696 --picker-models 64
# 候选构建后用另一个新 state、port 启动；不得在测量期间构建或换模块。
node scripts/webui-performance/measure-model-picker.mjs \
  --baseline http://127.0.0.1:24696 --candidate http://127.0.0.1:24697 \
  --browser /usr/bin/chromium --output /tmp/picker-measure-new --runs 7 --models 64
node scripts/webui-performance/verify-model-picker.mjs \
  --baseline http://127.0.0.1:24696 --candidate http://127.0.0.1:24697 \
  --browser /usr/bin/chromium --output /tmp/picker-behavior-new
```

输出目录必须不存在。停止 Runtime 后核对 `integrity.json` 的完整消息行摘要；使用模型夹具时还核对 `modelsBefore/modelsAfter`。
行为脚本会改变浏览器内的草稿选择和收藏，不能指向正式页面。

## 固定口径

- 1440/390px、CPU 1/4；LAN 20ms/100Mbps、弱网 800ms/1Mbps。CDP 不模拟丢包或真实软键盘。
- 每种设备独立预热目录、字体与模块；从实际 pointerdown、input 或 keydown 事件开始计时。
- `contentMs`：正确完整模型名集合、搜索词或无结果提示到齐，关闭时面板消失且焦点归还，再过两帧。
  `settledMs` 再等待面板动画结束和两帧；不把动画取消或占位出现当作完成。
- 每次保留打开、筛选、清空、无结果、再次清空、关闭六项。7 对 AB/BA 交错，网络顺序轮换，
  共 672 样本；每个设备/网络/动作/版本各 7 个样本。失败保留、进程非零退出，不剔除失败。
- 核对浏览器实际收到的模块字节及摘要，静态资源出现在热操作或请求失败即失败。
  请求时间相对动作监听开始；响应完成状态单列，不冒充 UI 的新鲜状态确认时间。
- 候选保留门槛在正式运行前冻结：每个设备/网络的打开正文中位数改善至少 15%；
  其它动作正文中位数退步不超过 `max(25ms, 基线的 10%)`；打开稳定时间不退步超过 25ms；零失败。
  这些门槛只用于本轮取舍，不替代全交互 300ms 目标。

## 行为与结果

行为脚本覆盖桌面、窄屏和短屏的完整目录、键盘选择、收藏/取消收藏、来源筛选、思考强度、
Esc 焦点归还、窗口重定位与窄屏遮罩。几何必须一致，截图相等性单独记录并人工核对边缘差异。
