## 核验与限制

- 真实浏览器验证 runtime 下载被 gate 阻塞时 SDK 预取不执行，以及 bootstrap 首次 503 后原页重试；均恢复为单个聊天实例，历史和草稿可用。修正测试服务退出处理后，在第二个隔离 Runtime 上再次通过这两项验证。
- 生产构建、前端 typecheck、插件边界检查和 diff 检查通过。对正常网络样本核对截图，没有改视觉样式。
- 主采样服务收到 SIGINT 后被 Uvicorn 重放信号中断了清理，未自动写出 integrity.json；随后用只读 SQL 与启动日志独立核对 100 条完整消息行，摘要相同。已在基准层修复信号 owner；第二个真实 Runtime 收到 SIGINT 后 exit 0，自动完整性报告前后一致。
- ready 采用 Playwright 的 visible 判定确认尾页正文已渲染，再读写草稿并等待当前会话 WebSocket 订阅确认；不做逐像素遮挡判定，也不发送消息或验证模型生成。
- CDP 限速、直连未压缩源站不能代表 Cloudflare、丢包或运营商链路。白屏缩短但未消除；高延迟冷启动 FCP 仍约 3.27s。
- 原始 JSON、逐 frame 瀑布、截图、构建副本和校验报告保留于 `/mnt/data/coding/benchmark-data/web-startup-20261013/`，未写入正式 workspace。未部署或合并。
